Entry for the [make.fun bounty "Five Seconds to Explain the Glass"](https://make.fun/bounty/u-po-pu-five-seconds-to-explain-the-glass-934d9949).

## The line

> The glass was a spy for the vacuum cleaner, so I dealt with it.

One sentence, 63 characters, spoken by a house cat in the five seconds
after sweeping a glass off the table. No apology, no confession, just
the cat's own defence: the glass was working for the vacuum cleaner,
the cat's oldest enemy, and the cat handled it.

## How it runs

`main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), with no trailing newline, as UTF-8.
It is deterministic, uses no network, no randomness and no clock.

```sh
python3 main.py
```
